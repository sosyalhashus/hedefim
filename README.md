# Hedefim

Mobil uyumlu, tek dosyalık hedef takip web uygulaması.

## Kullanım

`index.html` dosyasını tarayıcıda açın veya GitHub'a yükleyip Vercel ile yayımlayın.

## Özellikler

- Hedef ekleme ve silme
- Hedef ilerleme takibi
- Alt görev oluşturma ve tamamlama
- İlerleme analizi
- Tarayıcıda localStorage ile veri saklama

## Önemli

Bu bir ilk sürümdür. Kullanıcı hesabı, bulut veritabanı ve cihazlar arası senkronizasyon içermez. Veriler tarayıcıya özeldir; tarayıcı verilerinin silinmesi veri kaybına neden olabilir.
